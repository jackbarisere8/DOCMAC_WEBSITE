How to check +

On Windows, open PowerShell in your Downloads folder and run:

certutil -hashfile app-release.apk SHA256

On macOS or Linux:

sha256sum app-release.apk

To inspect the signing certificate on a computer with Android build tools:

apksigner verify --print-certs app-release.apk

The output must match the two values above. A checksum confirms the file matches what was published; Android still performs its own install checks.

More support
Is this the official Docmac download?

Yes. This page links directly to the official Docmac GitHub release and publishes a SHA-256 checksum for every version. Always download Docmac from this page and compare the checksum before installing.

Why does Android ask for permission to install?

Docmac is distributed as an APK, so Android may ask you to allow installs from the browser or file manager you used. This setting can be changed again in Android settings at any time.

Which version should I download?

The latest release is the recommended choice. It contains the newest fixes and is the version shown in the download card above. Older versions are kept for compatibility and testing.

Can I install an older version?

Yes, but Android may refuse to install an older version over a newer one. You may need to uninstall Docmac first, which removes local app data. Back up anything important before downgrading.

How do I verify the APK?

Use the SHA-256 shown in the verification section. On Windows run certutil -hashfile app-release.apk SHA256; on macOS or Linux run sha256sum app-release.apk. The result must match the published value exactly.

What Android version do I need?

Docmac supports Android 7.0 (Nougat) and newer. The minimum version is shown on each release card.
