About Android’s APK warning

Android or your browser may flag an APK downloaded from the web because it is not installed through Google Play. That warning does not by itself mean the file is harmful. This page links only to Docmac’s official signed GitHub release. Download only from this website, check that the file is named app-release.apk, and do not install modified copies from other sources.

Good to know

Questions, answered.

Is this the official Docmac download?+

Yes. This page links directly to the official Docmac GitHub release. Always download Docmac from this page or the linked release page.

Why does Android ask for permission to install?+

Docmac is distributed as an APK, so Android may ask you to allow installs from the browser or file manager you used. This setting can be changed again in Android settings at any time.

What Android version do I need?+

Docmac supports Android 7.0 (Nougat) and newer.
