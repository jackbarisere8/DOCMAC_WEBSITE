Installing Docmac

  1. Download the APK from the official Docmac release page.
  2. Open the completed download from your browser or Files app.
  3. If Android asks, permit that app to install unknown apps. This only allows the installation you initiated.
  4. Tap Install, then open Docmac and create or sign in to your account.

Need more help?

Quick answers

Before you write in.

The APK will not open. What should I do?+

Confirm the download finished, then open it from your phone’s Downloads or Files app. If Android blocks it, use the prompt to allow the specific browser or file manager to install apps.

Can I update Docmac later?+

Yes. Return to the official release page and install the newest APK when one is published. Android will update the existing app when it is signed with the same release key.

I cannot receive a verification code.+

Check that the phone number includes its country code, that your device has network service, and that you have not entered a recent code incorrectly. If the problem continues, contact us directly with the exact error message.
