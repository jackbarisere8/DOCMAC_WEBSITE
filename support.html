From download to first message.

Docmac installs directly from a signed APK. The steps below are the same on most Android phones; the wording may differ slightly by manufacturer.

  1. Download from this site. Use the official Docmac download. The button resolves to the latest signed APK on GitHub Releases, not a third-party mirror.
  2. Open the finished file. Use the download notification or your phone’s Files app. Wait until the transfer has fully completed before opening it.
  3. Allow installs from that source. Android may ask you to permit installs from your browser or file manager. This applies only to that app and can be changed again in Android settings.
  4. Verify, then install. Compare the APK’s SHA-256 with the value in the verification section or checksums.txt. If anything differs, stop and download the file again.

Docmac uses one signing certificate across releases. A matching certificate lets a new build update an older installation without clearing local app data.

Before you
write in.

A few problems have a simple fix. If yours does not, the contact details above reach the Docmac team directly.

The APK will not open. What should I do?

Confirm the download completed in your browser, then open the file from your phone’s Files app or Downloads folder. If Android shows a security prompt, open its settings and allow installs from the app you used to download the APK. The permission can be turned off again afterwards.

Can I verify the file before installing?

Yes. Check the SHA-256 in the verification section or view the machine-readable checksums.txt. On Windows run certutil -hashfile app-release.apk SHA256; on macOS or Linux run sha256sum app-release.apk. If you use checksums.txt, rename the downloaded file to the name shown there before running sha256sum -c checksums.txt.

Can I update Docmac without losing data?

Yes. Download the newer APK from the official page and install it over the existing app. Android accepts the update when the signing certificate matches. Back up anything important before a downgrade, because installing an older build may require uninstalling the current one.

I did not receive a phone verification code.

Make sure the number includes its international country prefix, your device has cellular reception, and SMS spam filters have not blocked the message. If the code still does not arrive, contact support with the number you used and the time of your attempt. Never send the code itself.

Which Android versions are supported?

Docmac supports Android 7.0 (Nougat) and newer. The current minimum version is also shown on the download card and on every release detail page.
